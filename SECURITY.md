# Security

Taxman is currently a planning repository. There is no released application or supported production version.

## Report privately

For a vulnerability or accidental sensitive-data exposure, use [GitHub's private vulnerability reporting](https://github.com/elliottolson/taxman/security/advisories/new). Include the affected location, a description of the issue, and a minimal reproduction using synthetic data.

Do not post credentials or financial documents in public issues. If you discover exposed data, describe its location privately rather than copying the data into a report.

For general design questions that do not reveal vulnerabilities or sensitive information, use a normal issue. The planned data controls are described in [Data and security](docs/data-and-security.md); they are design requirements, not implemented guarantees.
